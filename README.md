# Документація проекту Expedition API

---

## Стек технологій

Проект розроблено на базі асинхронного фреймворку FastAPI з використанням ORM SQLAlchemy для взаємодії з базою даних. Повний перелік залежностей:

* **Фреймворк:** FastAPI (0.139.0)
* **ASGI Сервер:** Uvicorn (0.51.0), Uvloop (0.22.1)
* **База даних та ORM:** SQLAlchemy (2.0.51), Psycopg2-binary (2.9.12)
* **Валідація даних:** Pydantic (2.13.4)
* **Автентифікація:** Python-jose (3.5.0), Passlib (1.7.4)
* **Робота з протоколом WebSockets:** Websockets (16.1)
* **Тестування:** Pytest (9.1.1), Httpx (0.28.1)
* **Моніторинг:** Sentry-sdk (2.64.0)

---

## Специфікація API ендпоінтів

Для доступу до захищених ендпоінтів необхідно передавати токен авторизації у заголовку:
`Authorization: Bearer <JWT_TOKEN>`

### 1. Модуль користувачів та автентифікації

#### Реєстрація нового користувача
* **Метод:** POST
* **Шлях:** `/users/register`
* **Формат тіла запиту:** JSON
* **Очікувані дані:**
  * `email` (рядок, валідний email)
  * `password` (рядок)
  * `role` (рядок, варіанти: `chief` або `member`)

#### Отримання токена доступу (Вхід)
* **Метод:** POST
* **Шлях:** `/users/token`
* **Формат тіла запиту:** application/x-www-form-urlencoded
* **Очікувані дані:**
  * `username` (email користувача)
  * `password` (пароль користувача)

---

### 2. Модуль керування експедиціями

#### Створення експедиції
* **Метод:** POST
* **Шлях:** `/expeditions/`
* **Доступ:** Авторизовані користувачі з роллю `chief`
* **Формат тіла запиту:** JSON
* **Очікувані дані:**
  * `title` (рядок)
  * `description` (рядок)
  * `start_at` (рядок у форматі ISO, дата та час початку)
  * `end_at` (рядок у форматі ISO, дата та час завершення)
  * `capacity` (ціле число, ліміт учасників)

#### Отримання списку експедицій
* **Метод:** GET
* **Шлях:** `/expeditions/`
* **Доступ:** Публічний
* **Параметри запиту (Query params):**
  * `skip` (ціле число, зміщення для пагінації, за замовчуванням 0)
  * `limit` (ціле число, ліміт результатів, за замовчуванням 100)

#### Отримання детальної інформації про експедицію
* **Метод:** GET
* **Шлях:** `/expeditions/{expedition_id}`
* **Доступ:** Публічний

#### Оновлення статусу експедиції
* **Метод:** PATCH
* **Шлях:** `/expeditions/{expedition_id}/status`
* **Доступ:** Авторизований `chief` (лише творець цієї експедиції)
* **Формат тіла запиту:** JSON
* **Очікувані дані:**
  * `status` (рядок, варіанти: `ready`, `active`, `finished`)
* **Бізнес-логіка переходів:**
  * Зміна статусу можлива лише послідовно: `draft` -> `ready` -> `active` -> `finished`.
  * Перехід у статус `ready` заблоковано, якщо в експедиції немає жодного підтвердженого учасника.

---

### 3. Модуль керування учасниками

#### Запрошення користувача до експедиції
* **Метод:** POST
* **Шлях:** `/expeditions/{expedition_id}/members`
* **Доступ:** Авторизований `chief` (лише творець цієї експедиції)
* **Формат тіла запиту:** JSON
* **Очікувані дані:**
  * `user_id` (ціле число, ID користувача, якого запрошують)
* **Правила валідації:** Запросити можна лише користувача з роллю `member`. Ендпоінт контролює ліміт `capacity` експедиції. Запрошення доступне лише для експедицій у статусі `draft`.

#### Підтвердження участі в експедиції
* **Метод:** PUT
* **Шлях:** `/expeditions/{expedition_id}/members/confirm`
* **Доступ:** Авторизований `member` (лише користувач, який отримав запрошення)
* **Формат тіла запиту:** Порожній
* **Правила валідації:** Підтвердження приймається лише якщо експедиція перебуває у статусі `draft`.

---

### 4. Шлюз реального часу (WebSocket)

#### Підключення до каналу оновлень
* **Протокол:** WS / WSS
* **Шлях:** `/expeditions/ws/updates`
* **Опис роботи:** Встановлює постійне двостороннє з'єднання. Пристрій-клієнт утримує з'єднання відкритим. 

#### Події бродкасту (Вхідні повідомлення)
При успішній зміні статусу будь-якої експедиції через PATCH-роут, сервер автоматично розсилає усім активним клієнтам WebSocket повідомлення у форматі JSON:

* **Структура події:**
  * `event` (рядок, значення: `"expedition_status_changed"`)
  * `expedition_id` (ціле число, ID оновленої експедиції)
  * `new_status` (рядок, новий статус)
  * `title` (рядок, назва експедиції)
